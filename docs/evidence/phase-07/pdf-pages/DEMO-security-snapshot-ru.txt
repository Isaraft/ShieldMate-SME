 2. Обнаружено несколько политик SPF
 merchant.example · средний · открыта

 Почему это важно: Несколько политик SPF для одного имени могут вызывать ошибки проверки почты,
 если домен отправляет письма.

 Следующий шаг: Попросите почтового администратора объединить разрешённых отправителей в одну
 политику SPF для этого имени. Не перезаписывайте TXT-подтверждение прав. Повторите разрешённую
 проверку DNS.

 Сохранённое точное число записей v=spf1 подтверждает множественность. Средний приоритет касается корректности
 настройки, а не взлома.
