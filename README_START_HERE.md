# ShieldMate Starter Kit — How to use with Codex

This kit is the authoritative repo context for ShieldMate SME Starter MVP.

1. Extract the contents of this ZIP into the **root of the project repository** (keep the relative directories intact). If existing files conflict, inspect them before overwriting.
2. In Codex, open that repository and send the entire content of `PROMPTS/PHASE_00.md`, or simply ask Codex to **read `PROMPTS/PHASE_00.md` and execute Phase 00 only**.
3. Make sure Codex can read `docs/design-references/brand-slide-01.png`, `brand-slide-02.png`, and `brand-slide-03.png`. These are your provided slide images and are **visual references only**.
4. After execution, capture Codex's summary, actual test output, outstanding blockers and `git status`; bring it to the chat for review. Do not immediately start Phase 01.
5. The separate phases and their acceptance criteria are in `PHASES.md`.

Important: `SHIELDMATE_MVP_SPEC.md` is an updated version of the older ShieldMate_MVP_TZ, with the correct **burgundy-and-RED** visual identity and the ten-phase plan. Use it instead of the old version if both files are present.
